# Security policy

This repository contains synthetic demonstration data only.

## Do not commit

- Client, matter, employee, or privileged information
- Tenant IDs, environment URLs, connection strings, API keys, or access tokens
- Power Platform connection exports containing personal account details
- Production prompts, retrieval sources, or audit logs containing confidential data

## Production safeguards

Before production use, complete information-security, privacy, records-retention, responsible-AI, legal, and platform-governance reviews. Configure least-privilege security roles, data-loss-prevention policies, managed environments, environment-specific connection references, and audit retention.

AI-generated content must be labeled as draft. High-risk and low-confidence results require human review. This project does not provide legal advice.
