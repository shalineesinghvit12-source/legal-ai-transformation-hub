# Synthetic Customer Identity Verification Policy

Status: Approved for portfolio testing  
Policy owner: Customer Operations  
Effective date: 2026-07-01  
Review date: 2027-07-01  
Classification: Synthetic public demonstration data

## Purpose

Define the information required before a customer can update contact details in the demonstration process.

## Requirements

1. The customer must provide the case reference shown in the original confirmation email.
2. The customer must confirm the current postal code held on the account.
3. Staff must not request passwords, full payment-card numbers, security codes or government identification by ordinary email.
4. If the case reference or postal code does not match, the request must be routed to the Identity Review queue.
5. Address changes must not be completed through an automated response. The response may explain the approved verification steps only.

## Customer response guidance

Use clear language. Request only the case reference and current postal code. Remind the customer not to send passwords or payment-card details. Do not state that an update has been completed.
