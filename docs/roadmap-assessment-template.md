# Technology roadmap opportunity assessment

Use this template during a quarterly Microsoft and legal-technology roadmap review.

| Field | Description |
| --- | --- |
| Capability | Feature or product capability being assessed |
| Source and date | Official roadmap or product documentation |
| Availability | Preview, general availability, regional limitations |
| Business problem | User or client need addressed |
| User groups | Practice groups, business services, IT teams |
| Expected value | Productivity, quality, risk, or client-service impact |
| Data involved | Classification and residency considerations |
| Integration | M365, iManage, Intapp, Litera, APIs, connectors |
| Governance change | New control, approval, logging, or policy needs |
| Adoption effort | Communication, training, and support implications |
| Recommendation | Experiment, pilot, monitor, defer, or reject |
| Next review date | Date and accountable owner |
