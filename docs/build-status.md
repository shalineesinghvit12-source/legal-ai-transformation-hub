## Requires a Microsoft tenant

The following items must be completed in the target tenant because Microsoft generates environment-specific IDs, connections, ownership, security metadata, and licensed AI actions:

- Dataverse tables and security roles
- Copilot Studio agent publication to Teams
- Power Automate cloud flows and connection references
- AI Builder model or approved AI-service action
- Power Apps model-driven application
- Microsoft Forms survey
- Power BI semantic model and report
- Power Platform managed and unmanaged solution exports
- DLP, auditing, retention, and managed-environment configuration

## Definition of deployed MVP

The tenant implementation is complete when all 15 UAT scenarios pass, the score matches the repository reference implementation, every human decision produces an audit event, dashboard totals reconcile to Dataverse, and no tenant identifiers or secrets are committed to GitHub.
